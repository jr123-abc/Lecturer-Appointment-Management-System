# Lecturer Appointment Management System (LAMS)

## 1. Project Overview

The Lecturer Appointment Management System (LAMS) is a web-based application developed to simplify and manage appointment scheduling between university students and lecturers.

The system provides separate functionalities for students, lecturers, and administrators to manage appointments and related academic activities efficiently.

## 2. User Roles

- **Student:** Register, view lecturer profiles, book appointments, cancel appointments, and view appointment history.
- **Lecturer:** Manage profiles, set availability, approve or reject appointment requests, and manage appointments.
- **Administrator:** Manage student and lecturer accounts, departments, faculties, and system activities.

## 3. Main Features

- User Authentication and Authorization
- Student Management
- Lecturer Management
- Appointment Booking and Cancellation
- Lecturer Availability Management
- Group Appointment Support
- Notification Management
- Administrator Dashboard
- Audit Logging
